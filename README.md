# ai-happy-02 — "A Note from Your Future Self"

A pure-Python-stdlib renderer (own PNG encoder over zlib/struct — no PIL)
that draws one warm letter on cream paper: a note from your future self,
sealed with red wax, telling the viewer the hard days pass, the good ones
stay, and to keep going. P.S. it gets better.

Run `python3 main.py` — it writes `/output/entry.png` (1024x1024 PNG,
deterministic: two runs produce byte-identical files).
